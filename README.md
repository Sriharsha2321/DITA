# DITA
Documents using DITA and Markdown
This repository contains markdown files.
The mark down files are categoized using DITA Topic Based Autoring i.e. each mark down file is considered as a topic that is task, concept, reference, glossary and troubleshooting.
All the mark down files are later converted to DITA XML, using java script automation programme.
All the DITA XML topics are arranged in DITA Map's to form a meaningful document.
