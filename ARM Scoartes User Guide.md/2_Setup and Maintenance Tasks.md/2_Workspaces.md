Socrates™ stores project references in a workspace. When Socrates™ starts, you are asked to
confirm the location that you want to use as a workspace. You can have multiple workspaces.

Procedure:
To select a workspace:

1. Open the **Select a directory as workspace window**. Either:

   * When socrtaes starts, the window opens automatically
   * When socrates is running, select **File> Switch workspace**.
   
2. In the slelect directory as workspace window, either:

    * **Browse** to the folder you want to use.
    * Expand Recent workspaces and select previously used folder.

3. Optionally, to use the same workspace every time Socrates starts, select **Use this as default and do not ask again**.
